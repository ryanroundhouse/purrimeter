# Preserve legacy endless gardens without granting every level unlock

Existing gardens remain playable in endless mode when the five-level progression arrives, preserving earned possessions and ongoing progress instead of forcing players into a finite level. New-garden access is separately credited from recorded highest cleared wave at 10, 20, 30, and 40, so a legacy player may continue an existing endless garden before earning permission to create another one.

This compatibility exception deliberately separates the current garden's mode from the player's unlocked choices. The exception survives rebirth, reloads, and transfers of that garden, but ends when New Garden replaces it. Implemented in the shared Godot game; see [the progression design](../five-level-progression.md).
