# Separate permanent level unlocks from garden progression

The five-level design makes level unlocks player-wide while keeping possessions, rebirth rewards, and wave progression scoped to a single garden. Starting any unlocked level creates a fresh garden, preserving meaningful starts and sequential progression without letting New Garden erase access the player has earned; carrying a powerful garden directly into the next level was considered and rejected.

Implemented in the shared Godot game. This extends the garden boundary in ADR 0014 and replaces the universal endless progression in ADR 0003 with four finite levels followed by an unlockable endless level. See [the progression design](../five-level-progression.md).
