Privacy policy

Purrimeter — The Garden Guard · Roundhouse Labs Inc. · Effective 1 November 2026

Purrimeter is a free game with no accounts, no advertising, no in-app purchases and no analytics or tracking libraries. This policy explains the little that the game does with your data, on every platform: Android, browser, macOS and Windows.

Data that stays on your device

Your garden (coins, cats, powerups, draft improvements, achievements and settings) is saved only on the device or browser profile you play on. We never receive it. The Export and Import actions let you move a copy yourself. Uninstalling the app or clearing site data deletes it.

Data sent during multiplayer

Multiplayer connects to a relay server, by default purrimeter.graham.pub, or a server you choose in Connection settings. While you are connected, the relay receives and forwards to the other players in your game:

  • the player name you typed, which can be anything you like;
  • your chat messages;
  • a live view of your playing field so the other players can watch it;
  • a random installation identity, stored on your device, that lets you reconnect to a game you dropped from.

The relay keeps this in memory only while the game is open. It does not store chat history, field updates or player names.

Reports

If you report another player's chat, the relay records that report so the server operator can act on it: the time, the game, both players' names and installation identities, and the reported player's most recent messages. Reports on the official server are kept for 90 days and then deleted. Reporting also mutes that player for you; nobody is notified.

Server logs

Like any web server, the official server records connection logs that include IP addresses and timestamps. These are used only to operate and protect the service and are rotated automatically.

Updates

At launch, and when you open Game updates, the game asks the selected relay server which release it currently requires. That request carries no personal data. On Android, updates are delivered by Google Play under Google's own terms.

Children

Purrimeter does not knowingly collect personal information from anyone, including children. Multiplayer chat is unmoderated beyond the mute, report and kick controls, so younger players should play with people they know or stay in single player.

Self-hosted servers

Anyone can run their own relay. When you choose a server that is not ours, its operator is responsible for how it handles the data listed above.

Changes and contact

If this policy changes, the new version is published at this address with a new effective date. Questions go to ryan@roundhouselabsinc.com.
